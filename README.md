# EventLens

EventLens is an event photography planning website. It helps a photographer or event organizer turn basic event details into a practical coverage plan before the event begins.

## What it does

1. Collects the event name, type, venue, date, schedule, attendance, photography team size, lighting environment, style, and important notes.
2. Sends those details to a small FastAPI backend.
3. When a Gemini API key is configured, asks Google Gemini to analyze the event and produce a structured plan.
4. Shows the plan on a dashboard, including event stages, key moments, shot priorities and techniques, coverage risks, photographer assignments, creative ideas, and a live shot checklist.
5. If Gemini is unavailable or no key is configured, creates a rules-based plan so the site can still be used. The dashboard labels this as non-AI output.

EventLens is a planning assistant. It does not take photographs, schedule staff, or store event plans on a server. Event data and the generated plan are kept in the browser's `localStorage` on the device used to create them.

## Run it locally

See [docs/setup.md](docs/setup.md) for the full Windows setup and startup instructions. In brief, the project needs a Python environment for the API and a local static web server for the HTML pages. Gemini is optional; without a key, the rules-based planner is used.

## API

- `GET /health` reports whether the backend is online and whether a Gemini key is configured.
- `POST /analyze-event` accepts an event JSON object and returns the event plus a structured photography plan.

See [docs/architecture.md](docs/architecture.md) for the request and response flow.

## Current scope and limitations

- In local development, the browser sends requests to `http://127.0.0.1:8000`. On Vercel, the website and API use the same origin.
- Plans are stored in browser `localStorage`; they are not synced across devices and may be cleared by the browser.
- The fallback planner uses templates and event details. It is useful when offline, but it is not generated by an AI model.
- A Gemini API key is required for Gemini-generated plans. Keep it in `backend/.env` and never put it in browser JavaScript.
- There is no user login, cloud database, image upload, or production hosting configuration in this project yet.
